# Hospital Asset Utilization & Capacity Planning Dashboard

An interactive Power BI dashboard that analyzes hospital asset utilization
and supports capacity planning decisions, built on PostgreSQL data with DAX measures.

## Dashboard Preview
![Dashboard](images/dashboard.png)

## Problem Statement
Hospitals need to know which assets (such as [beds / equipment / rooms]) are
underused or overloaded so they can plan capacity better.

## Tools Used
- PostgreSQL / SQL: data storage and querying
- Power BI: dashboard and visualization
- DAX: KPI and utilization measures
- Power Query: data cleaning and transformation
